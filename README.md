# Vue Multi-page Frontend — Team Project

A collaborative frontend project developed during the Boolean course.

![Vue](https://img.shields.io/badge/Vue_3-42b883?logo=vuedotjs&logoColor=white) ![Bootstrap](https://img.shields.io/badge/Bootstrap_5-7952B3?logo=bootstrap&logoColor=white)

## Pages and structure
- Home
- About Us
- Contact

The application uses Vue Router, shared header/footer components, Bootstrap and Sass.

## Technology
Vue 3, Vue Router, Vite, Bootstrap 5, Sass, Swiper, Font Awesome.

## Run locally
```bash
npm install
npm run dev
```
Build with `npm run build`.
